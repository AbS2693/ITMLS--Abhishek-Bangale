
EXERCISE 6.5 - TASK 3: GRAD-CAM VERIFICATION REPORT
====================================================

OBJECTIVE:
==========
Verify that Grad-CAM heatmaps correctly highlight the target objects in images
(pedestrians, traffic lights, vehicles).

METHODOLOGY:
============

For each model and visualization, we verify:

1. HEATMAP LOCALIZATION
   - Does the red/hot region appear where the target object should be?
   - Is the heatmap activating on relevant image regions?
   - Does it avoid activating on background/irrelevant areas?

2. SPATIAL ALIGNMENT
   - Are pedestrians in the top/middle of frame -> heatmap shows top/middle?
   - Are traffic lights typically centered -> heatmap shows center?
   - Are vehicles large -> heatmap shows substantial activation?

3. FEATURE DETECTION
   - For pedestrian model: Should activate on human shapes, movement
   - For traffic light model: Should activate on bright colored objects
   - For vehicle model: Should activate on large rectangular/structured objects

4. SPURIOUS FEATURES
   - No excessive activation on road surface (common false positive)
   - No excessive activation on sky/clouds
   - Activation concentrated on relevant objects
